# DataKernelBench project page

This folder contains the static project page for:

- `https://kerneldf.github.io/datakernelbench/`
- `https://kerneldf.com/datakernelbench/` while the custom domain is active

The page is deliberately dependency-free. Publish `index.html`, `styles.css`,
and `og.png` from the root of the `kerneldf/datakernelbench` GitHub repository
with GitHub Pages.

The research code and artifacts remain in
[`KernelDF/DataKernelBench`](https://github.com/KernelDF/DataKernelBench).
